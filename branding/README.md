# SociACL marks

Approved 2026-11-02. Signal yellow `#F5C400` on charcoal `#0E0F0C`.

The mark is the grant-rings glyph. SVG files in this folder are the sources. PNG files beside them are the favicon sizes, the apple-touch icon, the raster mark and wordmarks, and the Open Graph image.

The repository README shows `mark-256.png` and the theme-specific wordmark PNGs. GitHub does not render SVG in Markdown, so those rasters are what the README displays. The SVG sources stay here.

| File | Role |
| --- | --- |
| `mark.svg` | Grant-rings mark |
| `wordmark.svg` | Mark and wordmark for dark backgrounds (`#E8E6DC` type) |
| `wordmark-on-light.svg` | Mark and wordmark for light backgrounds |
| `favicon.svg` | Favicon on charcoal |
| `favicon-light.svg` | Favicon on white |
| `og.svg` | Open Graph card |
| `mark-128.png`, `mark-256.png`, `mark-512.png` | Raster mark |
| `wordmark.png`, `wordmark-on-light.png` | Raster wordmarks |
| `favicon-16.png` through `favicon-512.png` | Raster favicons |
| `favicon-light-16.png` through `favicon-light-512.png` | Raster light favicons |
| `apple-touch-icon.png` | Apple touch icon |
| `og.png` | Raster Open Graph image, 1200×630 |

This repository has no docs site. GitHub does not take a repository social preview from a file in the tree. `og.png` is the image to upload if that setting is changed.
